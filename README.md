# LifeFit — Умный контроль здоровья и привычек

Современное веб-приложение для комплексного отслеживания здоровья, активности, питания, сна и привычек с интерактивной геймификацией (персонаж, уровни, монеты, гардероб), расширенной сортировкой по всем разделам и встроенным бэкендом.

---

## 🚀 Быстрый запуск

### Вариант 1 (Рекомендуемый для Windows):
Просто запустите файл **`start.bat`** двойным кликом:
- Автоматически запускается локальный REST API сервер на PowerShell (`http://localhost:3000`).
- Открывается браузер с приложением.
- Все данные сохраняются на диск в `data.json`.

### Вариант 2 (Запуск сервера через PowerShell):
```powershell
powershell -ExecutionPolicy Bypass -File .\server.ps1
```

### Вариант 3 (Запуск через Node.js):
```bash
node server.js
```

### Вариант 4 (Запуск через Python):
```bash
python server.py
```

### Вариант 5 (Без сервера / Автономный режим):
Просто откройте файл **`index.html`** в любом браузере. Приложение работает автономно через `localStorage` и автоматически подключится к серверу при его появлении.

## 🌟 Возможности проекта

### 1. 🏠 Главная панель (Dashboard)
- **Динамический индекс здоровья** (0–100) с автоматическим расчетом на основе привычек, активности, гидратации и питания.
- **Система уровней и XP**: получайте опыт за выполнение целей, повышайте уровень и открывайте награды.
- **Интерактивный план дня**:
  - Базовые и **пользовательские привычки** (с возможностью добавления своих целей с эмодзи).
  - **Сортировка задач**: по умолчанию, сначала невыполненные, сначала выполненные, по алфавиту.
- **Трекер воды**: быстрый ввод (+250 мл, +500 мл, +1 л), сброс и прогресс-бар к персональной цели.
- **Трекер настроения**: 5 градаций с поддерживающими цитатами и советами.
- **График активности за 7 дней** и интерактивный распорядок дня.
- **Кнопки управления днем**: «Сохранить сейчас» и «Начать новый день» с начислением монет и продлением серии (streak 🔥).

### 2. ❤️ Моё здоровье (Health Analytics)
- Комплексные показатели: Индекс здоровья, Иммунитет, Энергия, Настроение.
- Факторы здоровья в реальном времени (вода, движение, дисциплина, рацион, эмоции).
- **Калькулятор ИМТ (BMI) и суточной нормы калорий / воды** по весу, росту, возрасту и полу.
- Персональные рекомендации для улучшения самочувствия.

### 3. 🏃 Тренировки (Sport & Stopwatch)
- **Встроенный секундомер / таймер тренировки** (старт, пауза, сброс, сохранение в историю).
- Быстрые шаблоны: Ходьба, Бег, Силовая, Велосипед, Растяжка/Йога, Плавание.
- Добавление пользовательских тренировок с указанием калорий и категории.
- **Журнал тренировок с поиском и сортировкой**:
  - По дате (сначала новые / старые)
  - По длительности (больше / меньше)
  - По сожженным калориям
  - По алфавиту

### 4. 🍎 Питание (Nutrition & Calorie Tracker)
- Чек-лист ключевых правил: овощи/зелень, белок, полезные жиры, без сахара, без еды перед сном.
- **Дневник питания**: запись блюд по категориям (Завтрак, Обед, Ужин, Перекус) с подсчетом калорий.
- **Сортировка и фильтрация приемов пищи**:
  - По времени записи
  - По калорийности
  - Фильтр по типам приёмов пищи

### 5. 😴 Сон (Sleep & Recovery)
- **Умный калькулятор фаз сна (90-минутные REM-циклы)** для легкого пробуждения.
- Дневник сна: время отбоя, подъема, расчет общей длительности, оценка качества (1–5 звезд), заметки.
- **Сортировка журнала сна**: по дате, длительности, качеству сна.

### 6. 🧑 Персонаж и Гардероб (Gamification)
- Интерактивный SVG-аватар с поддержкой смены цвета кожи, одежды, головных уборов и аксессуаров.
- **Магазин гардероба за заработанные монеты**:
  - Категории: Одежда, Внешность, Головные уборы, Аксессуары.
  - **Сортировка товаров**: по цене (возрастание/убывание), по названию (А-Я), сначала купленные / некупленные.
  - Поиск предметов по названию.

### 7. 📅 Неделя и Полный архив истории (History Archive)
- Сводная статистика за 7 дней.
- **Полная таблица архива дней с сортировкой**:
  - По дате (новые/старые)
  - По индексу здоровья
  - По минутам активности
  - По выпитой воде
  - По количеству выполненных целей
  - Фильтры по периодам (7 дней, 30 дней, всё время) и строке поиска.
- **Экспорт данных**: в CSV-таблицу и JSON-файл резервной копии.

### 8. 🏆 Достижения (Achievements)
- 11 разнообразных наград за рекорды серии, уровень, гидратацию, питание и монеты.
- **Сортировка и фильтры**: только полученные, в процессе, по награде, по названию.

### 9. ⚙️ Настройки и Бэкенд
- Настройка персональных целей: суточная норма воды (л), норма активности (мин), сна (ч), калорий (ккал).
- Настройка распорядка дня.
- Управление URL сервера REST API и кнопка мгновенной синхронизации.
- Резервное копирование (Экспорт/Импорт JSON).
- Переключение темы (Темная 🌙 / Светлая ☀️).

## 📡 REST API Бэкенда

- `GET /api/status` — проверка статуса сервера
- `GET /api/data` — получение актуальных данных в формате JSON
- `POST /api/data` — сохранение полного состояния
- `POST /api/reset` — сброс базы данных к начальному состоянию
- `GET /api/export` — выгрузка резервной копии `lifefit_backup.json`
